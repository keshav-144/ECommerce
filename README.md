# E-Commerce Web Application

## Overview

A full-stack E-Commerce web application developed using Spring Boot, Spring Data JPA, Thymeleaf, and MySQL. The platform provides separate functionalities for customers and administrators, including user authentication, shopping cart management, order processing, payment integration, and product management through an admin dashboard.

## Key Features

### User Features

* User Registration
* User Login & Logout
* Product Browsing
* Add to Cart
* View Cart
* Place Orders
* View Order Details
* Payment Integration

### Admin Features

* Admin Dashboard
* Add, Update, Delete Products
* Manage Orders
* Manage Customers
* Monitor Product Inventory

## Project Structure

* Controller Layer – Handles HTTP requests and responses
* Service Layer – Contains business logic
* Repository Layer – Manages database operations using JPA
* View Layer – Developed using Thymeleaf templates

## How to Run

1. Clone or download the repository.
2. Open the project in STS, Eclipse, or IntelliJ IDEA.
3. Configure MySQL database in `application.properties`.
4. Create the required database.
5. Build the project using Maven.
6. Run the main Spring Boot application class.
7. Open the browser and access the application.
